# 아이엠센터 홈페이지 디자인 규칙

> 대상: 센터 공개 홈페이지 `home/` (https://iamcenter.web.app)
> 기준: 메인 시안 v4 + 현재 운영 중인 `home/index.html`의 스타일 (2026-10-26 기준)
> 새 페이지·새 섹션을 만들거나 고칠 때는 **이 규칙을 먼저 따르고**, 여기 없는 모양은 이미 있는 부품을 재사용한다.

---

## 1. 디자인 원칙

1. **흑백 중심, 포인트 색은 아주 작게** — 검정(잉크)·흰색·옅은 베이지 회색으로 구성하고, 노란 포인트 색은 버튼 안의 작은 점 정도로만 쓴다.
2. **큰 글자와 넉넉한 여백** — 섹션 제목은 크고 굵게, 본문은 작고 차분하게. 섹션 사이 여백을 아끼지 않는다.
3. **선으로 구분, 상자는 최소화** — 표·목록은 위 2px 검정 줄 + 사이 1px 회색 줄로 나눈다. 둥근 모서리 카드·그림자는 쓰지 않는다(예외: 버튼·칩·편집 도구). 각진 칸이 필요하면 옅은 배경 위 흰 칸(`.fact-items`)이나 1px 검정 테두리 칸(탭)만 쓴다.
4. **사진이 주인공** — 사진 자리는 비워 두지 않고, 사진이 없으면 그라데이션 + `PHOTO · 설명` 표시로 자리를 잡아 둔다.
5. **정신없지 않게** — 색을 더 넣거나 장식을 늘리기보다 덜어 낸다. 강조는 굵기(800)와 크기로 한다.
6. **문서처럼 보이지 않게** — 정보가 많은 페이지(대관료·규약·교통)도 "작은 제목 + 표"만 나열하지 말고, 아래 3장의 섹션 제목·띠·단계 카드 같은 부품으로 리듬을 만든다.

## 2. 색 (CSS 변수, `:root`)

| 변수 | 값 | 용도 |
|------|----|------|
| `--ink` | `#0d0d0d` | 글자 기본색, 어두운 띠·푸터 배경, 기본 버튼 |
| `--paper` | `#ffffff` | 페이지 배경 |
| `--mute` | `#6b6b6b` | 보조 글자(부제·설명·표 머리줄) |
| `--line` | `#e3e3e3` | 1px 구분선 |
| `--soft` | `#f4f3f1` | 옅은 배경 띠(시설 안내·중심 가치·비고 상자) |
| `--accent` | `#f2b705` | 포인트 — **버튼 안 작은 점(`.btn .dot`)에만** |

- 본문 글자: `#333`~`#444`, 부드러운 설명: `#555`
- 어두운 띠 위 보조 글자: `rgba(255,255,255,.55~.65)`
- 교통 안내 구분 글자색만 예외적으로 파랑 `#3c6fa8` / 노랑 `#b8890b` / 빨강 `#b3473f` (버스 종류 구분용)
- 카카오 관련 아이콘·버튼: `#fee500`
- **새 색을 추가하지 않는다.** 필요하면 위 변수의 투명도만 조절한다.

## 3. 글꼴·글자 크기

- 글꼴: **Pretendard Variable** (CDN), 대체 `-apple-system, "Noto Sans KR"`
- `word-break: keep-all` (한글 단어 중간에서 줄바꿈 금지), 기본 줄 간격 1.6
- 크기는 `clamp(최소, vw, 최대)`로 화면에 따라 자연스럽게 변하게 한다.

| 역할 | 클래스 | 크기·굵기 |
|------|--------|-----------|
| 메인 히어로 제목 | `.hero h1` | `clamp(44px, 8.4vw, 132px)` / 800 / 자간 -.045em / 줄간 .95 |
| 세부 페이지 큰 제목 | `.page-hd h1` | `clamp(40px, 6vw, 88px)` / 800 / -.045em |
| 섹션 제목(영문) | `.sec-hd h2` | `clamp(34px, 4.6vw, 68px)` / 800 / -.04em / 줄간 1 |
| 페이지 안 작은 섹션 제목 | `.sec-hd.sm h2` | `clamp(30px, 3.6vw, 52px)` |
| 왼쪽 제목 칸 영문 | `.kv-h .kv-en` | `clamp(28px, 3vw, 42px)` / 800 |
| 섹션 부제(한글) | `.h2sub`, `.kv-h h3` | 15px / 500 / `--mute` |
| 작은 머리말 | `.eyebrow` | 12px / 600 / 대문자 / 자간 .18em |
| 큰 문장(선언문) | `.statement .big` | `clamp(28px, 4vw, 58px)` / **300** (강조만 800) |
| 소개 큰 문구 | `.hall-head`, `.sp-head` | `clamp(22~24px, 2.6vw, 32~34px)` / **400** (강조만 800) |
| 가운데 정렬 본문 | `.vision` | `clamp(17px, 1.6vw, 21px)` / 줄간 1.95 |
| 일반 본문 | — | 15~16px / 줄간 1.75~1.85 |
| 큰 숫자 | `.stat .n` | `clamp(38px, 4.4vw, 64px)` / 800, 단위 `small`은 .4em |
| 단계 번호 | `.st-n` | `clamp(30px, 3vw, 40px)` / **300**, `01` 두 자리 |

- **굵기 대비가 핵심**: 큰 문장은 가늘게(300~400) 쓰고 핵심 단어만 800으로. 편집 데이터에서는 `**굵게**`로 표시.
- 따옴표는 둥근 따옴표 `“ ” ‘ ’`를 쓴다(메인 소개 문구의 “ ” 안은 자동으로 굵게).

## 4. 레이아웃·여백

- 콘텐츠 폭: `.wrap` 최대 **1440px**, 좌우 여백 `--pad: clamp(20px, 4vw, 64px)`
- 글 위주 영역: `.wrap.narrow` 최대 **1100px**
- 섹션 위아래 여백: `section { padding: clamp(80px, 11vw, 160px) 0 }`
  - 탭 안 내용(`.g-sec`)은 `clamp(48px, 6vw, 88px)`
  - 같은 섹션 안 큰 덩어리 사이: `clamp(64px, 8vw, 112px)`
- 2단 배치 `.split`: `1.25fr 1fr`, 간격 `clamp(40px, 6vw, 96px)` — 사진 왼쪽, 글 오른쪽
- **왼쪽 제목 + 오른쪽 내용**(`.kv`): 왼쪽 `minmax(200px, 300px)`, 간격 `clamp(24px, 5vw, 80px)`
- 고정 헤더 높이 76px → 세부 페이지 머리는 `padding-top: calc(76px + clamp(56px, 8vw, 120px))`

### 반응형 기준
| 폭 | 바뀌는 것 |
|----|-----------|
| ≤1100px | 숫자 띠 4칸 → 2칸, 공연 카드 한 화면 3장 |
| ≤900px | 상단 메뉴 → 햄버거(☰), 2단(`.split`, `.kv`, 문의 띠) → 1단, 층별 안내 표 2칸, 단계 카드 3칸 |
| ≤760px | 중심 가치 세부 설명 3칸 → 1칸 |
| ≤600px | 숫자 띠 1칸, 단계 카드 2칸, 탭 2줄, 표 왼쪽 칸 96px |

- 모바일(폭 390px)에서 **가로 스크롤이 생기면 안 된다.** 넓은 표만 `.tbl-scroll` 안에서 가로로 밀어 본다.

## 5. 부품 (재사용 우선)

### 5-1. 섹션 제목 — `.sec-hd`
메인(What's On·Spaces·Visit·Floors)과 같은 모양: **큰 영문 제목 + 아래 작은 한글 부제**.
```html
<div class="sec-hd rv"><h2>Fees<span class="h2sub">대관료</span></h2>[오른쪽 보조: 단위·버튼 등]</div>
```
- `home.js`의 `secHd(enPath, 기본영문, 한글경로, 오른쪽내용, 'sm')`로 만든다. 영문·한글 모두 편집 모드에서 고칠 수 있음.
- 영문은 짧은 명사(Process, Contact, Fees, Facilities, Stage, Seating, Guidelines, Terms, Getting Here, Parking, Amenities, Accessibility, Floors, Visit…).
- 페이지 안에서 여러 번 나오면 `sm`(조금 작게).

### 5-2. 왼쪽 제목 + 표/목록 — `.kv` (`kvTable()`, `textList()`)
- 왼쪽: 영문 큰 제목(`.kv-en`) + 한글 작은 제목
- 오른쪽 표: `.info` 목록 — 위 2px 검정 줄, 줄마다 1px 회색 줄, 이름 칸 굵게(700), 값 `#333`, 이름 칸 폭 180px(모바일 96px)
- 오른쪽 목록 `.tlist`: 같은 줄 규칙 + 앞에 `•`/`-`, 굵게 가능
- **시설 안내 표(방문자 화면)**: 이름은 14px 회색, 값은 굵은 제목처럼(`clamp(19px,1.9vw,24px)` / 800). 값이 여러 줄이면(부속시설 등) 줄마다 흰 칸(`.fact-items`)으로 나눠 이름 굵게 + 수량 작게(“의자 48개” → **의자** / 48개). 편집 모드에서는 고치기 쉬운 일반 표로 보임.
- **값이 비어 있는 줄은 방문자에게 숨긴다.**

### 5-3. 표 — `.ptable`
- 위 2px 검정 줄, 가로 1px 줄만(**세로줄 없음**), 머리줄은 13px 회색 600, 배경색 없음
- 행 제목은 왼쪽 정렬·검정, 숫자 칸은 가운데
- 같은 구분이 이어지면 한 칸으로 합치고(`rowspan`) 오른쪽에만 1px 세로줄
- 금액이 비어 있으면 회색 “별도 문의”
- 단위·부가세 안내는 섹션 제목 오른쪽(`.unit`, 13px 회색)

### 5-4. 버튼 — `.btn`
- 기본: 검정 알약 모양(`border-radius: 999px`), 15px/700, 안쪽 여백 `17px 28px`, 앞에 노란 점 `.dot`, 뒤에 `→`(바깥 링크는 `↗`)
- 테두리 버튼 `.btn.line`, 작은 버튼 `.btn.sm`
- 어두운 배경 위에서는 흰 버튼 + 흰 테두리 버튼으로 뒤집는다.
- 마우스를 올리면 글자와 화살표 사이가 벌어짐(`gap 12px → 20px`).

### 5-5. 탭
- **페이지 탭 `.ptabs`**(대관신청·방문가이드): 1px 검정 테두리 안에 같은 폭의 칸, 칸마다 작은 영문(11px 대문자, 55%) + 한글 이름(17px 700). 선택된 칸만 검정으로 채우고 흰 글자, 마우스를 올리면 `--soft`. 모바일은 2칸씩 2줄. 주소 `&tab=키`로 바로 열림. **글자만 한 줄로 늘어놓은 탭은 쓰지 않는다**(문장처럼 보여 깨진 것처럼 보임).
- **필터 칩 `.tabs`**(What's On): 알약 모양 테두리, 선택되면 검정 채움.

### 5-6. 어두운 띠 — `.statement`
- 배경 `--ink`, 흰 글자. 페이지마다 1~2번만(너무 자주 쓰면 무거워짐).
- 숫자 칸 `.stats > .stat`: 4칸, 칸 사이 흰색 20% 세로줄, 큰 숫자 + 단위 + 제목 + 설명(흰색 65%). 예: 메인 WHY, 아이엠홀 숫자 띠.
- 문의 띠 `.r-contact`: 왼쪽 큰 “Contact” 제목, 가운데 이메일·전화(17~21px 600), 흰 버튼.

### 5-7. 단계 카드 — `.steps`
- 위 2px 검정 줄, 칸 사이 1px 세로줄, 칸마다 가는 큰 번호 `01` → 굵은 제목 → 작은 설명
- 4단계 이하는 한 줄, 5단계 이상은 3칸씩(모바일 2칸)

### 5-8. 사진
- **사진 자리 `.ph`**: 그라데이션(`--g`) + 아주 옅은 노이즈 + 왼쪽 아래 작은 표시 `PHOTO · 설명 · 비율`. 사진이 들어오면 `data-hasimg`로 표시가 사라짐.
  - 방문자 화면에는 “사진을 올려 주세요” 같은 관리자용 문구 대신 **무슨 사진이 들어갈 자리인지**를 적는다(예: `아이엠홀 객석·무대 · 가로 16:9`).
- 비율: 대표 사진 16:9, 페이지 띠 사진 21:9, 공연 포스터 3:4, 편의시설 3:2
- **사진 묶음 `photoSet()`**: 1장은 한 장, 2장 이상은 넘겨 보는 슬라이드(좌우 버튼 + 점)
- Spaces 카드 실제 사진에는 가장자리 비네팅 자동 적용
- 도면·약도·좌석배치도·QR처럼 **정보 그림**은 사진 자리 대신, 없으면 방문자에게 숨긴다(`imgSlot()`).
- 그라데이션 예: 공연장 `radial-gradient(ellipse 60% 70% at 50% 35%, #6a5238, #2a2019 45%, #0d0d0d)`, 기본 `linear-gradient(135deg, #2a2a2a, #111)`

### 5-9. 구분 점 — `DOTS`
- 회색 점 3개(`•••`, 7px, `#b5b5b5`) 가운데 정렬. 대표 사진과 소개 문구 사이 등 **분위기 전환 지점**에만.

### 5-10. 층별 안내 — `.bld` / `.fl-row`
- 2px 검정 테두리 상자 안에 층마다 한 줄(층 번호 | 공간 이름 | 소개 | 바로가기 버튼), 칸 사이 1px 세로줄, 위층이 위로.
- 바로가기 버튼은 옅은 작은 알약(홈페이지 안 = 회색 채움 `→`, 바깥 = 테두리 `↗`).

### 5-11. 헤더·푸터·퀵버튼 (모든 페이지 공통, 바꾸지 않음)
- 헤더: 히어로 위에서는 투명 + 흰 글자, 스크롤하면 흰 배경(96%) + 검정 글자 + 아래 1px 줄. 로고는 이미지 마스크라 글자색을 따라감.
- 오른쪽 “대관신청” 테두리 알약 버튼.
- 푸터: 검정 배경, 4칸(로고·주소 / MENU / INFO / RELATED), 링크가 비어 있으면 흐리게.
- 오른쪽 아래 둥근 퀵버튼(전화·카카오·맨 위로), 스크롤 후 나타남.

## 6. 움직임

- 공통 곡선 `--ease: cubic-bezier(.2, .7, .1, 1)`
- 나타나기 `.rv`: 아래에서 28px 올라오며 .9초 동안 나타남 → 새 덩어리에는 `rv` 클래스를 붙인다.
- 카드 사진은 마우스를 올리면 살짝 확대(1.05), 밑줄은 왼쪽에서 오른쪽으로 그려짐.
- `prefers-reduced-motion`이면 움직임 없음.
- 과한 애니메이션(튀는 효과, 회전, 깜빡임)은 쓰지 않는다.

## 7. 글·문구 규칙

- 섹션 제목 = **영문 큰 제목 + 한글 부제** 한 쌍
- 페이지 머리 = 영문 머리말(eyebrow) → 한글 큰 제목 → 한 줄 소개
- 설명 글은 줄바꿈으로 호흡을 나누고, 핵심만 `**굵게**`.
- 금액·면적은 단위를 붙여 쓴다(`2,500,000원`, `1,014m²`). 비어 있으면 “별도 문의”.
- 관리자용 안내 문구(“사진을 올려 주세요”, “+ 줄 추가” 등)는 **편집 모드에서만** 보이게 한다.

## 8. 편집 모드와의 약속 (개발 규칙)

- 화면 글자는 `t()`(한 줄) / `m()`(여러 줄) / `rich()`(굵게 가능) / `tf()`(값이 없으면 기본 문구)로 출력 → 편집 모드에서 바로 고칠 수 있게 된다.
- 사진은 `data-img`, 링크는 `href()`(=`data-link`), 목록 줄 추가·이동·삭제는 `arrAdd()`/`arrCtl()`.
- 새 항목은 `content.js`의 `DEFAULT_CONTENT`에 기본값을 먼저 넣는다. 배열 안 객체의 새 필드도 기본값에 넣으면 기존 게시본에 자동으로 채워진다.
- 편집 모드를 처음 열었을 때 아무것도 안 바꿨으면 반드시 **“변경 없음”**이 떠야 한다.
- `home/index.html`의 스타일을 바꾸면 `:root`의 `--css-ver`와 `home.js`의 `CSS_VER`를 **같은 새 값으로 함께 올린다**(브라우저에 남은 옛 스타일을 자동으로 새로고침하기 위한 표시).
- 작은따옴표 문자열 안에 곧은 따옴표(`'`)를 넣지 않는다(과거 이 실수로 홈페이지 전체가 안 뜸). 안내 문구에는 `“ ” ‘ ’`.
